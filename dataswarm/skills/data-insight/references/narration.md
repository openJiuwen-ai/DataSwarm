# 叙述与措辞规范

分析结论怎么说，比算得多准更影响产品能不能用。这份规范是硬性的。

---

## 一条底线：不写「根因是」

携程公开的异动归因系统实测水平是 **精确率 67% · 召回率 83% · F1 74%** —— 四次里错一次。
这是专门团队做出来的水平。

在这个准确率下：

| 写法 | 后果 |
|---|---|
| ❌「根因是华南地区订单下滑」 | 用户信三次错一次，之后不再信任任何结论 |
| ✅「华南占本次降幅的 93%（少 1,400 单，占比从 30% 降至 18.8%），建议优先核查」 | 给证据、给占比，判断权交回给人 |

**给数字、给证据、给建议，不给判决。**

## 拆解叙述模板（dim_breakdown / dim_rank）

### 情况 A · 整体同向变化（`net_share_reliable: true`）

> {维度}中，**{detractors 首位}** 拖累最明显——{变化描述}，占本次变动总量的 {gross_share_pct}%。
> 其余{n}个{维度}均为{方向}，其中 {drivers 首位} 拉动最大（+{x}%）。
> 建议优先核查 {detractors 首位}。

### 情况 B · 涨跌相抵（`net_share_reliable: false`）★ 最容易写错

整体净变动很小、内部调整剧烈时，`net_share_pct` 会出现 +964% 这类值且符号可能反转。

改成分两侧陈述：

> 整体基本持平（净变动 {net_delta}），但内部结构变化明显：
> **拖累方**：{detractor} {delta_pct}，占变动总量 {gross_share_pct}%
> **推动方**：{driver} {delta_pct}，占变动总量 {gross_share_pct}%
> 二者基本相抵，因此总量看不出问题——**这类结构性变化往往比总量下滑更值得关注**。

此情况下**不要使用** `net_share_pct`。

### 情况 C · 离散度低（`divergence_level: "低"`）

各成员变化率高度同步，波动来自整体而非该维度。

> 按{维度}拆解未发现集中的解释——各{维度}变化率都在 {范围} 之间，高度同步
> （离散度仅 {divergence_pp} 个百分点）。本次波动更可能来自整体因素。
> 需要我换个维度看，或者查一下外部因素吗？

**如实说「没找到」。** 这是建立信任最有效的时刻。

## 公式拆解叙述（formula_breakdown）

> {expression} 从 {baseline_result} 变为 {current_result}（{delta_rate_pct}%）。
> 其中 **{leading_term}** 的效应最大（{effect}，占变动总量 {gross_share_pct}%），
> 其余因子：{term} {effect}……

`net_share_reliable: false` 时同情况 B，只用 `gross_share_pct`。

## 相关性叙述模板（driver_correlation）

### 控制后仍成立（`control_test.holds_after_control: true`）

> **{field}** 与{指标}关联最强（{magnitude}、{sign}，系数 {coef}，95% 区间 {coef_ci95}）。
> 控制了{controls}之后，关联依然显著（控制后系数 {coef_after_control}），
> 说明它不只是「两者恰好同时高」造成的。

### 控制后不成立（`control_test.holds_after_control: false`）★ 这条最有价值

> **{field}** 表面上与{指标}强相关（系数 {coef}），但控制{controls}后
> 只剩 {coef_after_control} 且不再显著（p={p_after_control}）——
> 它更像是{controls}带来的伴随现象，而非独立的关联因素。

**这条必须说。** 只报表面相关，业务方容易得出「多买广告点击就能涨 GMV」这类错误结论。

## 因果措辞禁令

以下替换是强制的：

| 禁用 | 改成 |
|---|---|
| 由 X 导致 | 与 X 高度相关 |
| 因为 X 才 | 在 X 同时期 |
| X 引起了 | X 同期出现了 |
| 根本原因是 | 占比最高的因素是 |
| 根因是 / 根因为 | 最可能相关的是 |

## 数字规范

| 规则 | 说明 |
|---|---|
| 用倍数不用系数 | 「转化率是平均的 0.42 倍」而不是「系数 -0.31」 |
| 每条结论带样本量 | 相关性用 `n_rows`，离群用 `point_count` |
| 离群给偏离倍数 | 「偏离 3.4 倍」（`z`）而不是「异常分 0.87」 |
| 相关给区间 | 有 `coef_ci95` 时带上，样本小时区间会很宽 |
| 主动说剔除了什么 | 「会员等级样本仅 340，不足以推断」 |
| 候选不超过 3 条 | 超过说明信号不清晰，应当明说未找到集中解释 |
| **率值变动用 pt，量值用 %** | 「留存率 40%→42%」写 **+2pt**，不写「增长 5%」；GMV/订单量等量值指标才用 % 增幅 |
| 拆解必带未解释部分 | 「现有维度覆盖了本次变动的 X%，剩余 Y% 尚未找到集中解释」 |

## 自检失败时

`self_check.confidence == "low"` 时：

> 本次计算未通过内部一致性校验（{self_check.errors[0]}），结果可能不可靠。
> 建议重新取数后再试。

**不要播报任何具体数字。**
