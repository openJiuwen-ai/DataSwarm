# 能力选择

按完整请求、已有输入和剩余工作选择能力，不按“报告”等单词或工具数量硬分类。加载技能不锁定入口；缺数据或指标未命中不自动升级分析。

| 所需工作 | 能力 |
|---|---|
| 指标定义、适配的发布指标查询 | dw-metrics |
| 表目录与结构 | dw-db-connector |
| 授权查询、SQL 生成 | nl2sql；SQL-only 不执行 |
| 已有数据的明确计算 | data-insight 或可复核脚本 |
| 已有数据与结论排版 | dw-report |
| 新的解释、诊断、综合评估、开放探索 | dw-analysis |

复合请求可组合能力，同时保留全部目标；不把诊断缩成取数，也不把固定计算扩成经营分析。输入不足时明确缺项，遵守用户对补取和交付的限制。启动参数见 [runtime.md](runtime.md#start--context)。
