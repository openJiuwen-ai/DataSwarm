# 诊断方法选择

按当前疑点选择方法，不作为固定流水线；算法未发现单点异常仍可能存在结构变化。是否继续探索按SKILL.md的流程与当前behavior_policy判断，调用data-insight时读取所用算子的参数和解读说明。

| 问题 | 可选方法 |
|---|---|
| 变化是否存在、基线是否合适 | 比较期、趋势、周期与完整性核验 |
| 孤立异常还是持续变化 | outlier_scan、趋势或水平位移检查 |
| 哪些群体贡献变化 | dim_rank、dim_breakdown、分层比较或 SQL 聚合 |
| 公式各因子贡献 | formula_breakdown 或可复核公式分解 |
| 关联是否稳健 | driver_correlation、控制变量、替代解释、敏感性分析 |

比较期按业务语义与数据覆盖选择并披露，不挑区间突出结论。不同方法结果冲突时检查口径和假设，保留未解决差异。

输出解读随所选方法读取data-insight/references/下的同名算子文件；仅指标类型不明时补读metric-types.md，不预读全部计算文档。
