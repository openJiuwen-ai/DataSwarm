# 内容质量原则

渲染器保证结构与产物完整性；模型根据用户问题组织内容，不用条目数、图表数或特定措辞替代质量判断。

- 先直接回答问题，再给证据和必要解释。标题可用结论句或便于理解的主题；没有可量化数字的事实或局限也可成为有效结论。
- 关键数字引用来源，计算保留可审计的输入、方法与结果；文字数字须能复算。
- 比较方向、极值、排名和环比/同比与引用数据逐项一致；解释增长的影响时比较两期变化，不能用本期存量冒充增量贡献。派生数值先使用已有证据计算，正文沿用计算结论；算术恒等关系只验证数值一致，不证明具体业务机制的因果。
- 区分事实、解释和未知。诊断按需要检验替代解释，未检验的方向明确作为假设，观察性相关和贡献不直接证明因果。仅在方法支持时量化解释比例。
- 建议按用户需要给出对象、动作与验证方式；expected_impact 有依据再量化，缺依据可说明待验证或省略。
- 局限按实际证据披露，不凑条数：包括覆盖、采样、口径假设和未回答问题。
- 数字附正确单位，区分百分点与相对变化。用清楚准确的表达，统计“显著”需要相应检验支持。
- 视觉表达与结论对应，展示范围应清楚，避免混用不可比较的数据或通过选择性展示夸大结论。
- JSON 使用正常转义保存引号和换行，不以限制正文符号代替合法序列化。
